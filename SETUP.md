# MyTube setup

**Public repo:** https://github.com/keerthan4531-a11y/MyTube

## Quick start (full app)

1. Download **MyTube-source.zip** (complete LibreTube tree + MyTube changes + icons)
2. Unzip → open folder in **Android Studio**
3. Sync Gradle → Run on device/emulator

Or:

```bash
git clone --depth 1 https://github.com/libre-tube/LibreTube.git MyTube
cd MyTube
# Copy overlay files from this repo (see APPLY_ON_LIBRETUBE.md)
./gradlew assembleDebug
```
